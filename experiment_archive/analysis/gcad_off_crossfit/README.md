# SP single→multiple GCAD-on/off 修复结果

更新日期：2026-07-30

## 实验边界

- 原9组正式主实验不重新生成，均视为完整方案（GCAD-on）结果。
- 本修复只处理 SP single→multiple 的 GCAD-on/off 消融。
- 原始 off=0 完整保留；另执行一次预先固定的独立 off 生成重复，不按结果挑选。

## 修复内容

1. 修复 `multiple` 下游检测将同一份生成数据同时作为训练集和阈值验证集的问题。
2. on/off 均取83条生成序列，采用5折交叉训练；每条校准分数均来自未训练过该序列的模型。
3. 保留原99分位结果，但不再将其作为当前小样本下的主要 F1。83条校准数据不足以稳定估计99分位，交叉校准后 on/off 的99分位 F1 均为0。
4. 增加固定、无攻击标签参与的稳健阈值。每一折只用该折验证分数计算
   `median` 和 `MAD`，先将该折的测试分数标准化，再对5折标准化分数取均值：

   ```text
   z_fold = (score - median(validation_fold)) / (1.4826 × MAD(validation_fold))
   anomaly if mean(z_fold) >= 3.5
   ```

5. 同时报告 AUROC/AUPRC，避免只依赖单一阈值。

|---|---:|---:|---:|
| GCAD-on | 0.7904 ± 0.0207 | 0.8866 ± 0.0678 | 0.8161 ± 0.0794 |

| on−off | +0.7904 | +0.5659 | +0.2792 |

```text
2024: 0.8103

```

off 三个 seed 的稳健 F1 均为0。

## 独立 off 生成重复

第二次 off 使用与原 on 完全相同的 SSC 输入、模型、类别和提示词主体，只关闭
GCAD：

```text
原始生成：113
TOF 最终：110
正式独立训练/验证：88/22
正式99分位 F1：0
```

对第二次 off 进行相同5折检查（检测器 seed2024）：

| 模式 | 稳健 F1 | AUROC | AUPRC |
|---|---:|---:|---:|
| GCAD-on | 0.8103 | 0.8098 | 0.7261 |
| GCAD-off 第二次 | 0.0000 | 0.5641 | 0.5988 |
| on−off | +0.8103 | +0.2457 | +0.1273 |

## 为什么 off 仍为0

`multiple` 检测器按原项目设计只读取设备列，攻击以 Television 设备模式为主。
两次独立 off 生成均比 on 更频繁地覆盖该攻击模式：

| 数据 | 最终序列 | Television 出现数 | 与攻击设备模式完全重合的序列 |
|---|---:|---:|---:|
| on | 83 | 138 | 0 |
| off 第一次 | 110 | 160 | 4 |
| off 第二次 | 110 | 166 | 7 |

因此 off 检测器会把 Television 攻击模式学习为正常模式。第二次独立生成重复仍出现
相同现象，说明 off=0 不是一次调用失败，也不是只由训练/验证重用造成。

## 可用于论文的结论

SP single→multiple 在修复数据划分、采用5折未见样本校准并增加独立 off 生成重复后，
GCAD-on 仍稳定优于 GCAD-off。99分位 F1 在83条校准数据下不稳定，不应作为该消融的
唯一指标；稳健 F1、AUROC 和 AUPRC 的方向一致，且两次独立 off 生成均复现了攻击模式
被学习为正常模式的现象。
