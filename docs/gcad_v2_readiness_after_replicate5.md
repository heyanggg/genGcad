# GCAD v2 readiness after replicate-5

The project is not ready to enter GCAD representation v2. Replicate-5 established a credible support-aware Codex candidate-pool and deterministic-selection baseline through TOF, but the unchanged generated-only reconstruction-health gate failed. The target boundary remained intact, so there is no target result to justify parameter changes.

GCAD v2, Ranking, B/C/D, and the remaining cells must stay paused. Any future baseline protocol must be a new prospective replicate with reconstruction-health rules frozen before loss inspection; replicate-5 must not be repaired, re-split, threshold-retuned, or target-evaluated.
