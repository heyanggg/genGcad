# GCAD v2 final decision

Terminate the current GCAD directional-relation route for this SmartGen source dataset. Event-position representation repairs v1's window count, illegal channel, and split leakage defects, but the central predictive premise still fails: a capacity-controlled Mixer does not beat n-gram statistics on any fixed seed. Continuing to gradients or GSS would turn model sensitivity into unsupported evidence.

Replicate-5 remains the frozen A5 baseline and its reconstruction-health failure is unchanged. The official detector was not modified. Ranking stayed disabled. Target normal, target attack, and labels were not read.
