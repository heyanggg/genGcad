# GCAD v2 source decision

Representation sufficiency, legal-channel validation, and leakage-safe splitting passed. Source prediction failed: the selected capacity/loss lost to the best simple baseline for all three fixed seeds and in the mean.

Formal decision: **stop GCAD v2 at the source prediction gate**. Current SmartGen source data does not support reliable GCAD directional relation enhancement. Stable relations, mechanism controls, GSS reranking, Codex B5 generation, TOF, target access, and paired evaluation were not run. Thresholds were not lowered and no favorable seed was selected.
